\section{Related Work}
\label{sec:related}

\paragraph{Representations of units larger than a token.}
Language models build representations that span more than one token.
\citet{kaplan-etal-2025-tokens} show that when a word is split into several
subword tokens, early attention gathers the pieces into the final subtoken and
later layers write a whole-word representation into that position. Reading those
states with Patchscopes, they recover words for which no single vocabulary token
exists, which they read as a latent lexicon wider than the tokenizer's
vocabulary. Related work builds on the same picture to reshape model
vocabularies \citep{reif-etal-2026-vocab} and to show that attention gathers
information early while later layers work on the result
\citep{artzy-schwartz-2024-attend}. Closer to our phrases,
\citet{haviv-etal-2023-understanding} find that memorised idiom completions are
recalled in two stages: early layers promote the memorised token to the top of
the output distribution, and upper layers raise the model's confidence in it.
All of these concern a unit the model has finished reading, or a single token it
is about to emit. Ours is a phrase it has not read yet.

\paragraph{Reading hidden states.}
The logit lens \citep{nostalgebraist-2020-logitlens} projects an intermediate
state through the unembedding to ask what token it would predict. Patchscopes
\citep{ghandeharioun-etal-2024-patchscopes} generalises this by injecting the
state into an arbitrary prompt and letting the model write out what it finds,
which lifts the restriction that the answer be a single vocabulary item and so
allows multi-token answers. Both raise the same question: is what comes out what
the model would otherwise have used? We put that question to the test by
comparing against the model's own continuations on matched instances
(\S\ref{sec:disagreement}).

\paragraph{Recovering tokens the model has not yet produced.}
Our question was posed, in a more general form, by Future Lens
\citep{pal-etal-2023-future}: given the hidden state of a single token at
position $t$, can the tokens at positions $\geq t+2$ be recovered? They answer
with linear approximation and with a causal intervention, transplanting the
state into a different context and reading what the model then produces, and
report better than $48\%$ accuracy at some layers of GPT-J-6B. That transplant
is the technique Patchscopes later generalised, and our use of it is a direct
descendant. What is new here is the target. Future Lens scores the recovered
tokens against whatever the model itself would have written next, so the target
moves with the model. We score against the phrase, which is fixed in advance and
does not. That lets us ask two things they cannot: whether the same phrase comes
back across many different sentences (\S\ref{sec:stability}), and how the
intervention compares with the model's own behaviour on identical inputs
(\S\ref{sec:disagreement}).

\paragraph{Using what the state already knows.}
Hidden states carry information about behaviour that has not happened yet.
\citet{orgad-etal-2025-llms} show they encode more about whether a forthcoming
answer will be truthful than the output distribution reveals, and that probes
trained on this signal transfer poorly across datasets;
\citet{gekhman-etal-2024-fine} treat a model's prior knowledge of an item as a
measurable quantity that predicts downstream behaviour. Our probe is the same
kind of instrument pointed at a different question, and it shows the same
limited transfer across categories (Appendix~\ref{app:details}). A parallel line
of work spends this redundancy on speed: speculative decoding
\citep{leviathan-etal-2023-fast}, multi-token prediction objectives
\citep{gloeckle-etal-2024-better,aynetdinov-akbik-2025-babies}, early exit with
self-speculation \citep{elhoushi-etal-2024-layerskip}, and CLP
\citep{xie-zhou-2026-clp}, which reads a single hidden state to decide how many
drafted tokens to accept. These methods assume that upcoming tokens are
predictable in a usable way. We measure how far that holds for one well-defined
class of continuations, and say when it is reliable. We implement no decoding
method here and report no speed-ups of our own.
