# Code

## Rebuilding the paper's artifacts

```bash
python3 code/make_paper_numbers.py   # results/raw/ -> results/processed/paper_numbers.json
python3 code/make_tables.py          # -> tables/*.tex   (except the two example tables, hand-written)
python3 code/make_figures.py         # -> figures/*.pdf  (except protocol.pdf)
python3 code/make_schematic.py       # -> figures/protocol.pdf
```

All four are deterministic: two consecutive runs produce byte-identical output.
PDF creation timestamps are suppressed for this reason.

`tables/disagreement_examples.tex` and `tables/falsepos_examples.tex` are
hand-written (they hold qualitative examples, not computed values) and are not
regenerated by these scripts. Do not delete them when rebuilding.

## Experiment scripts

`phrase_recognition/` holds the scripts that produced `results/raw/` on the
cluster. They need a GPU and the model weights; they are here for provenance and
are not run as part of the paper build.
